# CampusEats Frontend

React frontend for CampusEats, built with Vite and Tailwind CSS.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

`npm run dev` starts the local Vite server, usually at `http://localhost:5173/`.

`npm run build` creates a production build in `dist/`.

## Environment

Vite only exposes browser environment variables prefixed with `VITE_`.

```bash
VITE_GROQ_API_KEY=your_groq_key
VITE_API_URL=https://api.campuseats.tusharsaini.tech
```
