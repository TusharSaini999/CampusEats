## 🚀 Getting Started

1. Fork the repository on GitHub.
2. Clone your forked repository:

   ```bash
   git clone https://github.com/your-username/CampusEats.git
   ```
3. Navigate to the project directory:

   ```bash
   cd CampusEats
   ```

---

## ⚙️ Development Setup

### Prerequisites

Make sure you have the following installed:

* Node.js (v16+ recommended)
* npm or yarn
* MySQL Server
* Git

### Installation

1. Install backend dependencies:

   ```bash
   cd backend
   npm install
   ```

2. Install frontend dependencies:

   ```bash
   cd ../frontend
   npm install
   ```

3. Configure environment variables:

Create a `.env` file in the backend folder and add:

4. Start the development servers:

Backend:

```bash
npm run dev
```

Frontend:

```bash
npm start
```

## 📋 Contribution Guidelines

Please follow these guidelines:

* Write clean, readable, and maintainable code.
* Follow existing project structure.
* Add comments where necessary.
* Test your changes before submitting.
* Keep commits small and meaningful.

---

## 🔁 Pull Request Process

1. Create a new branch:

   ```bash
   git checkout -b feature/your-feature-name
   ```

2. Make your changes and commit:

   ```bash
   git commit -m "Add: your feature description"
   ```

3. Push your branch:

   ```bash
   git push origin feature/your-feature-name
   ```

4. Open a Pull Request on GitHub.

---

## 🐛 Reporting Issues

If you find a bug:

1. Check existing issues first.
2. Open a new issue with:

   * Clear title
   * Steps to reproduce
   * Expected behavior
   * Screenshots/logs (if applicable)

## 💡 Feature Requests

Have an idea? We’d love to hear it!

Open an issue and label it as `enhancement`. Include:

* Problem description
* Proposed solution
* Benefits

## 🎯 Style Guide

### Code Style

* Use ESLint standards (if configured).
* Follow React and Express best practices.
* Use meaningful variable and function names.

### Commit Messages

Format:

```
Type: Short description
```

Examples:

* `Fix: resolve login bug`
* `Add: payment integration`
* `Update: improve UI responsiveness`
